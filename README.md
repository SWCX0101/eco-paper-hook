# PAPERHOOK · 四语言外贸独立站

纯静态多语言站点，支持 English / 简体中文 / Русский / العربية。

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 语言入口，按浏览器语言自动跳转，也可手动选择 |
| `en/` `zh/` `ru/` `ar/` | 各 7 个页面，共 28 页 |
| `assets/style.css` | 共享样式，含 RTL 镜像规则 |
| `assets/main.js` | 共享脚本，含语言偏好记忆与询价表单 |
| `assets/img/` | 12 张图片，四语言共用 |
| `sitemap.xml` | 28 URL × 5 组 hreflang |
| `robots.txt` | 指向 sitemap |

## 本地预览

```bash
python3 -m http.server 8899
# http://localhost:8899/
```

## 修改内容

页面由 `/root/.codebuddy/artifact/.../build_i18n.py` 生成（`site_core.py` + `page_*.py`）。
直接改 HTML 也可，但重新生成会覆盖。

## 部署

GitHub Pages，`main` 分支根目录。推送后约 1 分钟自动生效。

## 文件结构

```
eco-paper-hook-site/
├── index.html        首页（品牌主张 + 数据 + 产品线 + 纸塑对比 + 场景标签）
├── eco.html          环保主张（法规时间线 + FSC 链条 + 承诺）
├── products.html     产品中心（6 种钩型 + 规格表 + 包装 + FAQ）
├── custom.html       定制服务（5 个定制维度 + 打样流程 + 交期表）
├── cases.html        应用场景（12 个场景 + 行业对照表 + 陈列方式 + 案例）
├── about.html        工厂实力（设备产能 + 里程碑 + 赔付承诺）
├── contact.html      联系我们（WhatsApp / 邮箱 / 询价表单）
└── assets/
    ├── style.css     全站样式（含响应式）
    ├── main.js       抽屉菜单、滚动动效、数字滚动、询价表单
    └── img/          12 张配图
```

## 如何打开

- **本地双击** `index.html` 即可浏览，页面之间可正常跳转。
- **本地服务器（推荐）**：在本目录执行
  ```bash
  python3 -m http.server 8080
  ```
  然后访问 http://localhost:8080

## 部署

纯静态，无需后端，直接上传整个目录到任意静态托管即可：

## 说明

- **全站不含任何价格**：单价、打样费、阶梯报价均已移除，价格由业务在询价环节单独沟通。
- 起订量、交期、承重等技术参数保留，方便客户自我筛选。

- 配图为 AI 生成示意图，用于展示产品形态，不是实物拍摄。
- 规格参数为行业常规区间，正式对客时建议替换为实际检测数据。
- 询价表单为前端 mailto 提交，不依赖服务器；如需收集到后台，可接入表单服务或自建接口。
